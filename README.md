# Rhizome

Rhizome es un sistema para la generación procedural de mapas 2D
utilizado en videojuegos o simulaciones.

## Descripción

El sistema permite generar mapas automáticamente utilizando algoritmos
procedurales configurables por el usuario.

## Características

- Generación automática de mapas
- Configuración de parámetros
- Evaluación de calidad
- Visualización del mapa

## Tecnologías

- Python
- Streamlit
- Supabase

## Instalación

git clone https://github.com/usuario/rhizome.git

cd rhizome

pip install -r requirements.txt

## Uso

streamlit run app.py
